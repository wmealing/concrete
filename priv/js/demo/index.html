Concrete demos

Every demo is pure Erlang, compiled to JavaScript, running in your browser. Each one listens on its own port.

Counter

The smallest possible demo: a self-rescheduling counter loop, pure Erlang compiled straight to JavaScript.

http://localhost:8765/

Template / Scoreboard

A .slab template rendered server-side on first load, then hydrated -- button clicks dispatch to a compiled action/3 running in the browser.

http://localhost:8766/

Todo List

A small stateful app (add/complete/clear) persisted to localStorage, entirely compiled Erlang -- no server round trips.

http://localhost:8767/

Canvas Animation

A self-scheduling animation loop drawing a rotating flower on <canvas> via the canvas:* BIFs.

http://localhost:8768/

gen_server-style Process

A real spawn/self/!/receive generic-server loop (concrete_gen_server.erl) dispatching into a callback module, running in the browser.

http://localhost:8769/

Process Ring (spawn/self/send/receive)

Six spawned worker processes passing a token around a ring, with a live canvas visualization of every send/receive hop.

http://localhost:8770/

Multiplayer Snake

A real gen_server owns the board and broadcasts it over SSE to every connected browser -- open it in two tabs and watch both snakes move live.

http://localhost:8771/

WebSocket Actions & Commands

Plain JavaScript, no compiled bundle -- every click sends a real action/command message over one WebSocket to concrete_ws_handler, dispatched server-side. The counter is a gen_server, so it survives a reload.

http://localhost:8772/

three.js Spirograph

A rotating, color-cycling spirograph drawn with three.js, loaded from a CDN <script> tag -- every THREE.* call is compiled Erlang, reaching the library through concrete_js, with no hand-written JavaScript at all.

http://localhost:8773/

Task Board (component mount + <:for>)

A keyed, dynamic list of stateful child components rendered with <:for> -- each task keeps its own persisted state across every re-render, and its mount/2 fires exactly once, the moment it first appears.

http://localhost:8774/
